### Hi there 👋 I'm Ramazan Muslu

I am a passionate software engineer, systems administrator, and network engineer based in Aydın, Turkey. With a strong foundation in backend development, systems architecture, and telecommunications infrastructure, I enjoy building scalable applications, automated workflows, and high-performance networking solutions.

---

### 👨‍💻 Professional Summary
* **Software & Game Development:** Experienced in building custom web applications, APIs, and multiplayer networking frameworks. Creator of **YoraCore**, a custom server-authoritative multiplayer networking framework built on Riptide.
* **Network Engineering:** Active experience in managing ISP infrastructure, including Optical Line Terminals (OLT), ONTs, TR-069 ACS management systems, and high-speed fiber optic routing.
* **Systems Administration & DevOps:** Over 5 years of hands-on experience in configuring, hardening, and maintaining Linux environments (with a primary focus on Debian servers and Arch-based distributions), Docker containers, Nginx, and WireGuard VPN architectures.

### 🚀 Key Projects & Works
* **[NeonRise](https://github.com/RamazanMuslu):** A 3D mobile FPS game developed in Unity C#, powered by a custom multiplayer networking framework (**YCore** / **RiptideNetworking**).
* **[MangaTurk](https://github.com/RamazanMuslu):** A collection tracking and cataloging system specifically designed for physical manga titles published in Turkish, featuring a Python FastAPI backend with HMAC-SHA256 authentication and a native Android application built with Jetpack Compose.
* **[Brawl Stars Ping Meter](https://github.com/RamazanMuslu):** A network monitoring Android application utilizing a native C++ ICMP ping library via Android NDK, achieving over 10,000+ downloads on the Google Play Store.
